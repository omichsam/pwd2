This folder contains records of changes made to the PWD Access Kenya system.
Use it for implementation summaries, release notes, upgrade notes, and future
change records.

## Recording future changes

Each substantial update should record:

- the date and version or release identifier;
- the purpose and affected subsystem;
- code, configuration, and database changes;
- migrations and rollback considerations;
- security, privacy, accessibility, and operational impact;
- tests and verification performed;
- known issues and remaining release gates.

Use an ISO date in incremental update filenames, for example
`2026-09-15-certificate-update.md`.
